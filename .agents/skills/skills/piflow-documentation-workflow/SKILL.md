# PiFlow 文档工作流

通用方法论由 Superpowers 负责。本技能只承载 PiFlow 项目文档约束。需要通用创意与需求澄清时引用 `superpowers:brainstorming`，需要实施计划时引用 `superpowers:writing-plans`，完成任务前验证时引用 `superpowers:verification-before-completion`。
本技能不重复上述通用方法。

## 文档路由

- 所有新建或更新的项目文档使用中文，必要技术标识除外。
- 将设计放入 `docs/superpowers/specs/`。
- 将实施计划放入 `docs/superpowers/plans/`。
- 将可复用知识放入 `docs/knowledge/`。
- 将 UI/交互交接放入 `docs/handoffs/`。
- 同一任务或主题更新现有文档，不创建竞争记录。

## PiFlow 记录要求

- 长期知识记录现象、根因、长期规则、验证方法。
- 交接记录分支、worktree、基线、预览端口、验证结果、风险、未合并状态。
